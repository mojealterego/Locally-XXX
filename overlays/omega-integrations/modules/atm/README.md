# ATM — Axiomatic Transcendence Matrix v1.0.0

Samodzielna dokumentacja inżynieryjno-wdrożeniowa. Zawiera PDF, DOCX, Markdown, 54 wymagania, 12 ADR, 30 scenariuszy testowych, JSON Schemas, oraz uruchamialny ograniczony rdzeń referencyjny Python.

Uruchom:

```bash
python -m unittest discover -s tests -v
python verification/verify_contracts.py
python reference_atm/demo.py
```

Konieczna jest dalsza implementacja Rust/Android/OCX/OmegOS. Bez zgody nie dokonano zmian w `Locally-XXX/main`. Status GATE-09 OPEN.
